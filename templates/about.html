ABOUT THE PROJECT

PlantCare AI

A Deep Learning based plant disease detection system.

🌱

Project Overview

PlantCare AI is a web-based plant disease detection system developed using Deep Learning, Computer Vision and Flask.

The system accepts an image of a plant leaf, preprocesses the image and uses a trained Convolutional Neural Network to classify the image as healthy or diseased.

Technologies Used

🌐 Flask
🧠 TensorFlow
🤖 Keras
📷 Computer Vision
💻 HTML & CSS
